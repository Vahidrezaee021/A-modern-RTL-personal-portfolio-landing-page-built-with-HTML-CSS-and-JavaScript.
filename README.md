# A-modern-RTL-personal-portfolio-landing-page-built-with-HTML-CSS-and-JavaScript.
This project is a Persian RTL personal portfolio landing page designed to showcase profile, services, skills, and contact information in a clean and modern interface.
## Features
- Fully responsive layout
- RTL Persian support
- Modern dark UI with elegant gradients
- Smooth section design and visual hierarchy
- Easy to customize for personal branding
## Tech Stack
- HTML5
- CSS3
- JavaScript
- Google Fonts (Vazirmatn)
